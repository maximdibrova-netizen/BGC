# BGC Точки

Игра с точками в духе мини-игры из BGC: захват клеток цепными взрывами.

- 1 на 1, против 2 или 3 ботов, или онлайн с друзьями по ссылке
- 5 карт, 4 уровня ботов
- перемотка ходов, отмена хода, подсказка лучшего хода, оценка позиции и разбор ошибок

Играть: https://maximdibrova-netizen.github.io/BGC/

## Как устроено

- `src/core.js` — правила, карты и боты (поиск с альфа-бета-отсечением)
- `src/ui.html` — интерфейс, анимации, звук, онлайн (PeerJS, прямое соединение браузеров)
- `build.py` — собирает `index.html` из этих двух файлов
- `index.html` — готовая игра, её и раздаёт GitHub Pages
